## Most Likely Causes:

### Cause 1: JavaScript File Not Loading (90% likely)
**Symptoms:**
- Buttons do nothing
- No network requests
- Console shows "Failed to load dashboard.js"

**Fix:**
Check file exists: `frontend/dashboard.js`
If missing → Restore from backup

### Cause 2: CORS Blocking Requests
**Symptoms:**
- Console shows "CORS policy blocked"
- Network request shows CORS error

**Fix:**
```batch
# Restart backend (already fixed CORS)
# Press Ctrl+C in backend window
Accountability.bat
```

### Cause 3: Backend Not Responding
**Symptoms:**
- Test page shows "Backend is NOT running"
- Network requests timeout
- Console shows "Failed to fetch"

**Fix:**
Check backend console for errors, restart if needed

### Cause 4: Function Not Defined
**Symptoms:**
- Console shows "login is not defined"
- JavaScript loaded but functions missing

**Fix:**
dashboard.js may be corrupted
