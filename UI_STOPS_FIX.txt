## STEP 2: Check for JavaScript Errors

**Look for these errors in Console:**

### Error A: "Failed to load resource: dashboard.js"
```
GET http://127.0.0.1:8000/frontend/dashboard.js net::ERR_FILE_NOT_FOUND
```
**Cause:** JavaScript file not loading
**Fix:** Check file exists at: `frontend/dashboard.js`

### Error B: "Uncaught SyntaxError"
```
Uncaught SyntaxError: Unexpected token...
```
**Cause:** Syntax error in dashboard.js
**Fix:** Check line number shown in error

### Error C: "login is not defined"
```
Uncaught ReferenceError: login is not defined
```
**Cause:** JavaScript not loaded or function not defined
**Fix:** dashboard.js file corrupted or not loading

### Error D: "Failed to fetch"
```
Failed to fetch
```
**Cause:** Backend not responding
**Fix:** Check backend is running (see console window)

## STEP 4: Check Network Tab

**In browser console (F12):**
1. Click **Network** tab
2. Click the register button
3. Look for **auth/register** request

**What to check:**

### Scenario A: No network request appears
**Cause:** JavaScript not running at all
**Symptoms:** Nothing in Network tab when you click
**Fix:** Check Console tab for JavaScript errors

### Scenario B: Request shows "CORS error"
**Error:** `Access-Control-Allow-Origin`
**Fix:** Backend CORS issue (already fixed, restart backend)

### Scenario C: Request shows 400/401
**Cause:** API rejected request
**Fix:** Click the request, check Response tab for reason

### Scenario D: Request shows (failed)
**Cause:** Backend not reachable
**Fix:** Restart backend

```javascript
// Test 1: Is API_BASE defined?

```

**Results:**
- If API_BASE is undefined → dashboard.js not loaded

## STEP 6: Common Fixes

### Fix 1: JavaScript Not Loading
**Check:**
```
frontend/dashboard.js file exists?
frontend/dashboard-styles.css file exists?
```
**If missing:** Files got deleted somehow

### Fix 2: CORS Error
**Solution:**
```batch

# Press Ctrl+C in backend window, then restart
Accountability.bat
```

### Fix 3: Backend Not Running
**Check backend console window:**
- Should say "Application startup complete"
- Should NOT show errors
- Should NOT be closed

**Restart if needed:**
```batch
Accountability.bat
```

### Fix 4: Cache Issue
**Clear browser cache:**
- Press Ctrl+Shift+Delete
- Check "Cached files"
- Click Clear
- Refresh page (Ctrl+F5)
