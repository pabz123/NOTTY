## Problem: Icon starts but then stops/closes abruptly

This means something is crashing during startup. Let's find out what!

---

```batch
debug-start.bat
```

✅ Test each component before starting

✅ Keep console open after crash
✅ Show exit code

**Watch for:**
- Where exactly it fails

---

## STEP 2: Check What's Happening

The app closes when:

### Issue A: Backend Can't Start
**Symptoms:**
- Console shows Python error
- "ModuleNotFoundError" or "ImportError"
- Port 8000 error

**Fix:**
```batch
# Delete venv and recreate
rmdir /s /q .venv
Accountability.bat
```

### Issue B: Electron Crashes
**Symptoms:**
- Console shows "Failed to start application"
- Exit code 1 or 3221225477
- JavaScript error

**Fix:**
```batch
# Reinstall Node modules
rmdir /s /q node_modules
npm install
Accountability.bat
```

### Issue C: Frontend JavaScript Error
**Symptoms:**
- Window opens briefly then closes
- No console errors in launcher
- Exit code 0

**Fix:** Check for syntax errors in dashboard.js

### Issue D: Python Import Error
**Symptoms:**
- "No module named 'pydantic_settings'"
- "No module named 'fastapi'"
- Backend window shows error

**Fix:**
```batch
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## STEP 3: What debug-start.bat Will Show

**If backend test fails:**
```
Testing if backend can start...
ERROR: Backend started but is not responding!
Check the "Backend Test" window for errors.
```
→ Look at the Backend Test window for Python errors

**If Electron crashes:**
```
Application Stopped
Exit Code: 1
```
→ Look above for error messages

**Common Exit Codes:**
- `0` = Clean exit (but shouldn't close immediately!)
- `1` = General error
- `3` = Configuration error
- `3221225477` = Crash/Access violation

## STEP 4: Manual Backend Test

Open Command Prompt in the app folder:

```batch
# Activate venv
.venv\Scripts\activate

# Test imports
python -c "import fastapi, uvicorn; print('OK')"

# Start backend manually
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

**Watch for:**
- Import errors → Reinstall packages
- Syntax errors → Share the error message
- Port errors → Kill processes first
- "Application startup complete" → Backend works!

If backend starts successfully, the issue is with Electron.

If backend fails, the issue is with Python/packages.

## Common Causes:

### 1. Missing Python Packages
```
ModuleNotFoundError: No module named 'pydantic_settings'
```
**Fix:** `.venv\Scripts\python.exe -m pip install pydantic-settings`

### 2. Port 8000 Stuck
```
[Errno 10048] Only one usage of each socket address
```
**Fix:** `debug-start.bat` handles this automatically

### 3. Node Modules Corrupted
```
Error: Cannot find module 'electron'
```
**Fix:** `rmdir /s /q node_modules && npm install`

### 4. Python Not in PATH
```
'python' is not recognized as an internal or external command
```
**Fix:** Reinstall Python with "Add to PATH" checked

### 5. Electron Crashes Silently
**Fix:** Run `debug-start.bat` to see the actual error
